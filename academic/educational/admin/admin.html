Supabase 连接设置

项目默认读取根目录的 config/supabase.json（http 访问时）或 config/supabase.js（直接双击 html 打开时），两个文件内容一致、所有访问者共用。下面的输入仅用于临时改用其它项目或本机调试——保存后只对当前浏览器生效，并会覆盖上面的配置文件。

云端写入账号（可选，推荐）

默认「简易模式」下（执行过 database/rls-anon-write.sql），任何拿到 anon key 的人都能写入数据；执行过 database/rls-strict.sql 则只有登录了 Supabase 账号的人能写，此时必须先在这里登录才能上传/保存。登录成功后上传请求会携带该账号身份，登录状态只保留到关闭浏览器标签页为止。

首页「系统通知与提醒」

保存在云端后，首页会优先显示这里的内容，保存即生效，不用重新部署网站。支持 Markdown：- 列表、1. 编号、**加粗**、[文字](链接)、> 引用、--- 分隔线。

教师任课名单

按「年级 → 班级」维护班主任与各科任课教师；保存后基础分析里的「班主任 / 任课教师」立即按云端名单显示。把某个科目留空再保存，等于删除该科目的任课教师。

整年级表格编辑 一次填完整个年级的班主任与各科教师，最下面点「保存整个年级」即可

教师账号

姓名即账号；密码以「加盐哈希」保存，云端表里没有明文。云端有账号时登录页优先用云端，表为空时回退 data/teacher-accounts.js。
